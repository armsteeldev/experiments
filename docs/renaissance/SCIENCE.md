# Scientific model boundaries

This review compares the visitor-facing descriptions in `src/data/experiments.json` with the implemented equations, discrete rules, and the checks that run in this repository. It is an implementation audit, not a scientific certification. Passing code checks establish behavior at selected inputs and invariants; they do not establish agreement with a laboratory system, convergence for every setting, or independent specialist approval.

The About panel exposes each short model description through **Read the underlying idea**. The copy now identifies important approximations in that same place, where a visitor can see them before treating a visualization as a physical prediction.

## Nineteen-study evidence ledger

| Study | Implemented model and evidence in this repository | Boundary and remaining validation gap |
| --- | --- | --- |
| **01 · The Infinite Shore** | Iterates `z ← z² + c`; `test:numerics` checks bounded/escaping reference points and the deep-zoom worker’s perturbation, repair and pixel-color paths. | The displayed image has finite precision and a bounded maximum zoom. The mathematical set continues beyond what a particular render can resolve. |
| **02 · A Quiet Current** | A compact 2D grid transports velocity and dye with semi-Lagrangian interpolation and a finite pressure projection; browser checks exercise pointer input, pause, reset, saved settings and the Canvas 2D fallback. | Projection reduces divergence but is not an exact incompressibility guarantee. The WebGL shader’s divergence residual and convergence across grid sizes do not yet have a numerical regression check; this is not a calibrated flow prediction. |
| **03 · A Murmuration** | Rule-based agents use local separation, alignment and cohesion, with additional predator, competition, vortex and visitor-placed field scenarios. `test:flocking-grid` compares neighborhood and vector calculations; browser checks verify interaction and bounded replay settings. | This is a stylized 2D behavioral model, not a validated account of a bird species, perception or flight. There is no comparison against observed flock data. |
| **04 · Weather, Remembered** | Five nonlinear ODE systems are advanced with a finite-step fourth-order Runge–Kutta integrator; the trail uses bounded storage and the browser checks system switching, camera controls and route cleanup. | The trail is a numerical trajectory, not a proof that a given parameter set has a strange attractor. Solver step-refinement and reference-trajectory checks remain open. |
| **05 · The Pattern Beneath** | Two bounded concentration fields follow a Gray–Scott-style reaction and a discrete 9-point diffusion stencil; browser checks cover painting, presets, saved starts and GPU/Canvas 2D settings recovery. | Feed/kill parameters and concentrations are dimensionless. The interface illustrates pattern formation; it does not simulate a specific organism or validate a biological mechanism. GPU field convergence and a reference-solver comparison remain open. |
| **06 · A Grammar of Growth** | Coral, sea fan and geometric studies use parallel symbol rewriting and drawing commands. The fern and tree use separate seeded parametric botanical generators; `test:fern` checks determinism, bounds and parameter response for those two. | The fern and tree are not L-systems, and none of these pictures is a plant-physiology simulation. The grammar rewrite path has no dedicated numerical reference suite yet. |
| **07 · Gravity Playground** | Newtonian pair forces use a Plummer-style softening length; velocity-Verlet advances motion in normalized scene units. `test:simulations` checks the force against a finite-difference gradient of its matching potential, momentum in a collision-free pair, a circular orbit, and relative energy drift below 0.3% for one collision-free orbit. | That energy result is for one setup and step size. Contact response, merges, fixed/manual bodies and larger steps are outside that bound; collision choices are simplified. The softened model is not a scale-calibrated solar-system prediction. |
| **08 · Inside the Machine** | A four-register, 8-bit teaching machine executes a bounded instruction set over 16 memory cells; each simulated tick executes one modeled instruction. `test:simulations` checks fetch/decode/execute staging, arithmetic wrap, branches, memory and task programs. | This abstracts selected instruction flow. It is not a transistor-level CPU or a cycle-accurate model of caches, pipelining, interrupts, waveforms or a commercial instruction set. |
| **09 · Neural Networks** | A small feedforward network applies weighted sums and activations; online gradient descent updates half squared error. `test:simulations` now checks a selected backpropagation gradient against finite differences for tanh, sigmoid and ReLU, and checks deterministic XOR training behavior. | The color field is the current model output, not a measure of performance on unseen data. The synthetic teaching examples and small architecture do not establish generalization. |
| **10 · Logic Laboratory** | Boolean gates evaluate from validated inputs in dependency order; unconnected pins remain unknown and cycles are reported. `test:simulations` checks gate composition, missing inputs, cycles and invalid wires; `qa:logic-sharing` builds and reloads a working XOR circuit. | This is combinational Boolean logic. It has no clocked state unless an exhibit explicitly represents it, and it does not model electrical delay, voltage or analog behavior. |
| **11 · Invisible Forces** | Softened charge contributions define a vector field and scalar potential; tests check a dipole, a field line and now the field against the negative finite-difference gradient of that same softened potential. | Coordinates and force scales are normalized; source singularities are deliberately smoothed. The test-particle path uses discrete Euler-style steps and is not itself a field line or a validated charged-particle experiment. |
| **12 · Cellular Automata** | Conway’s Life, HighLife, Seeds and Brian’s Brain update from the current cell and its eight neighbors on a wrapped grid. `test:simulations` checks representative transitions and now includes a birth across the wrapped edge. | These are exact implementations of the selected discrete rules, not models of cell biology or continuously varying physical processes. |
| **13 · The Adder** | Ripple and Kogge–Stone circuits are explicit Boolean gate graphs. `test:adder` checks truth tables, traces, carry and signed overflow, architecture agreement, and every input pair for 4-bit and 8-bit adders. | Exhaustive arithmetic evidence applies to the tested widths and circuit definitions. It does not claim a speed advantage for one architecture in this visual playback. |
| **14 · The Wave Chamber** | A damped, second-order finite-difference wave field obeys a tested two-dimensional Courant bound; tests check propagation, bounded amplitude, superposition, solid barriers, selected cavity response and probe bounds. | The sources drive the field, damping removes energy, and the edge sponge is only a graded damping layer. The displayed energy is a local estimate, not a conserved total; the continuum wavelength estimate can differ from the dispersive discrete grid. |
| **15 · A Geometry of Light** | Explicit ray/segment intersections use vector reflection, Snell refraction, total internal reflection and a paraxial thin-lens rule. Tests cover analytic intersection/reflection/refraction cases, prism dispersion, off-axis lens behavior and the opening scene. | Rays carry direction but not realistic brightness. The model omits diffraction, interference, polarization, Fresnel intensity, lens aberrations and thick-lens behavior. |
| **16 · The Shape of Sound** | Fourier partials drive both the sampled waveform and a Web Audio `PeriodicWave`; tests check harmonic bins, phase, preset coefficients, a digital low-pass response and the amplitude cap. Browser checks verify playback remains visitor-initiated and the audio context closes on route exit. | This is a periodic oscillator, not an instrument or room model. Automated signal checks do not establish subjective sound quality; no human listening evaluation has been performed. |
| **17 · The Living Garden** | Seeded agents search for finite resources, spend energy, inherit bounded traits with mutation and reproduce under population limits. Unit checks verify seeded starts, energy costs and inheritance bounds; documented stress runs span 37,000 accelerated model steps. | Time, metabolism and other quantities are illustrative model units. There is no predation, calibrated ecological data or specialist validation; population outcomes demonstrate this rule set only. See [`phase2-review.md`](../invisible-world/phase2-review.md). |
| **18 · The Living Network** | A discrete-time graph routes each hop with Dijkstra costs based on latency and queue depth; checks cover failures, recovery, delivery, overflow, disconnected paths and bounded routing. Browser checks complete and reroute messages. | This is a focused routing study, not TCP/IP, congestion control, transport reliability or Internet-scale traffic. See [`phase2-review.md`](../invisible-world/phase2-review.md). |
| **19 · Where Light Falls** | Equatorial null geodesics in a non-rotating Schwarzschild plane are integrated with RK4. Checks compare weak-field deflection with `4M/b`, halve angular step size, check mass scaling and monitor the impact invariant; worker output is checked against synchronous raster output. | The sky is a thin-lens projection of a synthetic source plane; the luminous disk is artistic. This is not finite-camera ray tracing, radiative transfer or a Kerr model. Independent specialist physics and art review remains outstanding. See [`phase2-review.md`](../invisible-world/phase2-review.md). |

## Reference context

These primary sources support the names and broad ideas used above; they do not independently validate this implementation:

- Jos Stam, [“Stable Fluids” (SIGGRAPH 1999)](https://doi.org/10.1145/311535.311548), a computer-graphics fluid-motion method.
- Edward N. Lorenz, [“Deterministic Nonperiodic Flow” (1963)](https://journals.ametsoc.org/doi/abs/10.1175/1520-0469%281963%29020%3C0130%3ADNF%3E2.0.CO%3B2), on bounded numerical solutions and sensitive nonperiodic trajectories in nonlinear systems.
- Craig Reynolds, [“Flocks, Herds, and Schools: A Distributed Behavioral Model” (SIGGRAPH 1987)](https://www.cs.toronto.edu/~dt/siggraph97-course/cwr87/), the original computational flocking study.
- John E. Pearson, [“Complex Patterns in a Simple System” (Science 1993)](https://doi.org/10.1126/science.261.5118.189), on patterns in a simple reaction–diffusion model.
- Aristid Lindenmayer, [“Mathematical Models for Cellular Interactions in Development II” (1968)](https://doi.org/10.1016/0022-5193(68)90080-5), one of the original developmental systems papers behind L-systems.
